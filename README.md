## Help

Common problems and fixes:

Images not showing – check the file path and name in the src match the real file exactly, including capital letters and the file extension
Styles not applying – make sure style.css is linked after Bootstrap in the <head>, and that every { in the CSS has a matching }
Icons missing – check the Bootstrap Icons <link> is in the <head> and that you're connected to the internet
Changes not appearing – save the file (Ctrl + S) and hard refresh the browser (Ctrl + F5)
Something else broken – press F12 in your browser and look at the Console tab for red error messages
